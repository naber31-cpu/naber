# ASTROBURROW ADVANCE 🛸

A sideways-handheld (GBA-style) space colony platformer in a **single HTML file**.
Mine, build, fight, rescue your crew, survive the raids and escape the planet —
a full **~30 minute campaign** of 13 missions, then endless free play.

**Play:** open `index.html` in any browser (phone in landscape = full handheld experience),
or serve the repo with GitHub Pages.

## Controls

| Handheld | Keyboard | Action |
|---|---|---|
| D-pad ◄ ► | Arrows / A D | Move (double-tap = dash) |
| D-pad ▼ | S / ↓ | Interact · mine (hold at a glowing node) |
| A | Space / Z | Jump (hold = Jetglide when unlocked) |
| B | X / K | Attack with current weapon |
| SELECT | Q / Tab | Cycle weapon (in build mode: cycle building) |
| BUILD | V / M | Toggle build mode (inside the Core zone) |
| START | Enter | Pause menu (quests, wheels, inventory, settings) |
| — | Shift / C | Dash |
| — | N | Mute |

## The campaign

Follow the golden objective banner: collect ore → power the base → smelt ingots →
clear the alien pests → build turrets → survive raids → climb east with MAG-GRIP for
crystals → rescue 3 stranded crew → upgrade the Core → craft the Rescue Beacon →
defend it against the final assault and the **Broodmother**.

## Systems

- **Weapons:** Plasma Cutter (melee), Pulse Pistol, Mining Blaster (mines from range), Repair Beam
- **Traversal:** Boost dash, MAG-GRIP wall climbing, Jetglide
- **Base building:** 15 buildings — generators power miners, smelters, assemblers, hydroponics, turrets…
- **Colony sim:** crew NPCs eat food and produce resources; storage caps; oxygen management in the field
- **Raids:** waves attack your Core — turrets, your Guard, and you defend it
- **Autosave** to localStorage, chiptune synth audio, screen-shake, particles, scanlines

Built on the original Astroburrow v14 asset set.
